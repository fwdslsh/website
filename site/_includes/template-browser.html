Built in

Shipped inside the unify CLI, so they need no network: unify init blog.

default

What unify init writes with no argument: a layout, a nav, a 404 page, and example about and contact pages to copy.

unify init

basic

The smallest start: a layout, a nav, a home page and a 404 page, with a contact page as the example.

unify init basic

blog

A post list written by a generator, with an example post and authors file to copy into place.

unify init blog

docs

A documentation site with an all-pages index, and an example guide page to copy.

unify init docs

portfolio

A portfolio with example work and project pages to copy.

unify init portfolio

On npm

Every package named unify-<name>-template or @scope/unify-<name>-template, straight from the npm registry: unify init <package>.
