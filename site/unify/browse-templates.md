# Browse templates

Every template you can start a site from. The five built into the CLI need no network; they are also on npm, beside every template anyone has published with the `unify-template` keyword. Each card opens the template's README in a new tab, and the command on it scaffolds the site. [How templates work](/unify/templates.html) covers the rest.
