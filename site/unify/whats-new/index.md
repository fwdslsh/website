# What's new

What changed in unify, written up by theme so the thread shows: fewer commands, fewer flags, and a project layout with a place for everything. Each write-up names the version that shipped each change. The version-by-version record is the [changelog](https://github.com/fwdslsh/unify/blob/main/CHANGELOG.md), and every release is on the [releases page](https://github.com/fwdslsh/unify/releases) with its binaries.
