# About fwdslsh

<p class="lede">fwdslsh is a small group of indie developers working together. There's no company behind it. We build tools we want to use, publish them as open source, and write up what we learn along the way.</p>

</header>

<section>

## The lab

"The lab" is where we try things out: new tools, odd ideas, and experiments with AI agents and the web. Whatever works becomes a tool. Whatever we learn becomes a [blog post](/blog/index.html).

</section>

<section>

## How we like to build

- **Small tools.** Each one does a job you can understand in one sitting.
- **Plain formats.** HTML, JSON, Markdown and the command line, so our tools fit into your own scripts.
- **Built for agents and people.** We use AI agents to help build our tools, and we design them so agents can use them too.

</section>

<section>

## Say hi

Everything is on [GitHub](https://github.com/fwdslsh). Issues and pull requests on any of our repos are welcome.

</section>
