# Slash a path through the bloat

fwdslsh is a small group of indie developers working together. We build open-source tools, try things out in the fwdslsh lab, and write up what we learn.

Right now that's mostly tools for a web that AI agents and people both use: sites that are easy to publish and easy to read, by eye or by agent.

[See the tools](/tools.html) · [Read the blog](/blog/index.html)

## Tools

- **[unify](https://unify.fwdslsh.dev/)**: a static site generator for plain HTML. Write a layout or nav once, and it lands on every page. This site is built with it.
- **[rabit](/rabit/index.html)**: a small JSON manifest that tells agents what a site holds and where, so they don't have to crawl for it.
- **[akm](https://github.com/itlackey/akm)**: one library of skills, scripts and knowledge for any coding agent that can run shell commands.
