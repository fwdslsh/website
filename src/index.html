rabit

Manifest-based navigation for AI

A simple convention for publishing content that both humans and AI agents can navigate reliably, using .burrow.json manifests.

$ rabit map ./docs --title "My Docs"
$ rabit validate docs/.burrow.json
$ rabit list https://example.com/docs

Why we built it: AI agents need structured paths, not HTML soup.

unify

HTML-native static site generator

Write a header, nav, footer, or layout once in plain HTML and unify renders it into every page. No expression language, no client runtime — this site is built with it.

$ npm install -g @fwdslsh/unify
$ unify init
$ unify build

Why we built it: Sharing chrome across pages shouldn't require a framework.

The Path Forward

Old-school principles, new-school execution

We're not building the next unicorn framework. We're building tools for hackers who value craft over hype.

Ship binaries, not ecosystems: Download once, run everywhere. No package manager roulette or dependency hell.

Hack with the grain: Work with web standards and POSIX conventions instead of reinventing everything.
